# 🕵️‍♂️ Real-Time Thief Detection System using YOLOv5 and OpenCV

## 📌 Overview
This project presents an AI-powered surveillance system designed to detect suspicious activities and intruders in high-value asset locations such as supermarkets, jewelry shops, and warehouses. Using the YOLOv5 object detection algorithm integrated with OpenCV, the system enables real-time monitoring, threat detection, and alert generation to enhance security efficiency.

## 🎯 Features
- Real-time intruder detection using YOLOv5
- ROI (Region of Interest) selection for focused surveillance
- Instant alert triggering with sound and image capture
- False positive/negative handling mechanisms
- High-quality image snapshots for evidence
- User-friendly interface for ease of deployment

## 🛠️ Technologies Used
- Python
- OpenCV
- YOLOv5 (PyTorch)
- NumPy

🧪 Dataset
For training or testing purposes, the system can use any standard object detection dataset, or CCTV video feeds for simulation. You can also create a custom dataset labeled in YOLO format using LabelImg.
